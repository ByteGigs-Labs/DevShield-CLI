# SH005: dangerouslySetInnerHTML without sanitizer

**Severity:** medium · **Category:** security · **Applies to:** nextjs, react

## Why it matters

Rendering raw HTML bypasses React's escaping. If any part comes from a user, it becomes a cross-site scripting hole.

## How to fix

Sanitize the HTML with DOMPurify before rendering, or render text instead.
