# DX001: No automated tests detected

**Severity:** medium · **Category:** developer_experience · **Applies to:** all projects

## Why it matters

Without tests, refactors and dependency upgrades are risky and regressions ship unnoticed.

## How to fix

Add a test runner (Jest/Vitest, PHPUnit/Pest) and cover the critical paths.

## Ignoring this rule

Skip it everywhere in `devshield.yml`:

```yaml
ignore:
  - DX001
```

Or skip one line with a comment on that line or the line above:

```text
devshield-ignore: DX001
```
