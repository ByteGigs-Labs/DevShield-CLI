# SH010: Sensitive file in Laravel public directory

**Severity:** high · **Category:** security · **Applies to:** laravel

## Why it matters

Everything inside public/ is served by the web server, including backups and dumps.

## How to fix

Move the file out of public/ and delete any copy that was already deployed.

## Ignoring this rule

Skip it everywhere in `devshield.yml`:

```yaml
ignore:
  - SH010
```

Or skip one line with a comment on that line or the line above:

```text
devshield-ignore: SH010
```
