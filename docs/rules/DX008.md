# DX008: .gitignore missing or incomplete

**Severity:** low · **Category:** developer_experience · **Applies to:** all projects

## Why it matters

Without it, dependencies, build output and local files get committed by accident.

## How to fix

Add a .gitignore for your stack that covers dependencies, build output and .env.

## Ignoring this rule

Skip it everywhere in `devshield.yml`:

```yaml
ignore:
  - DX008
```

Or skip one line with a comment on that line or the line above:

```text
devshield-ignore: DX008
```
