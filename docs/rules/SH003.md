# SH003: Security headers not configured

**Severity:** medium · **Category:** security · **Applies to:** express, nestjs

## Why it matters

Headers such as Content-Security-Policy and Strict-Transport-Security block whole classes of attacks (XSS, clickjacking, protocol downgrade) with no application changes.

## How to fix

Install helmet and add `app.use(helmet())` before your routes (in NestJS, in main.ts).
