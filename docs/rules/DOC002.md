# DOC002: No license

**Severity:** low · **Category:** documentation · **Applies to:** all projects

## Why it matters

Without a license nobody else may legally use, modify or distribute the code.

## How to fix

Add a LICENSE file (choosealicense.com can help you pick one).

## Ignoring this rule

```yaml

  - DOC002
```
