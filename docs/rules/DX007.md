# DX007: Inconsistent version numbers

**Severity:** low · **Category:** developer_experience · **Applies to:** all projects

## Why it matters

Different versions in different manifests make releases and rollbacks confusing.

## How to fix

Keep one source of truth for the version and derive the others from it.
