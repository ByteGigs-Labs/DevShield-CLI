# DX010: Secret printed in workflow logs

**Severity:** high · **Category:** security · **Applies to:** github_actions

## Why it matters

Echoing a secret writes it to the build log, where encoding tricks defeat masking.

## How to fix

Pass the secret through an environment variable and never echo it.
