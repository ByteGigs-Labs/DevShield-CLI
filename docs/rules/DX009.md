# DX009: Large file committed

**Severity:** low · **Category:** developer_experience · **Applies to:** all projects

## Why it matters

Large binaries bloat the repository permanently, because history keeps every version.

## How to fix

Store them with Git LFS or in object storage.

## Ignoring this rule

Skip it everywhere in `devshield.yml`:

```yaml

  - DX009
```

