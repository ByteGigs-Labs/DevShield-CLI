# DOC003: CONTRIBUTING or CHANGELOG missing

**Severity:** info · **Category:** documentation · **Applies to:** all projects

## Why it matters

Contribution guidelines and a changelog help others adopt and upgrade the project.

## How to fix

Add CONTRIBUTING.md and CHANGELOG.md.
