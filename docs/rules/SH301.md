# SH301: .env.example missing or incomplete

**Severity:** low · **Category:** configuration · **Applies to:** all projects

## Why it matters

A committed .env.example documents which settings the application needs. Without it new developers and deployments have to guess.

## How to fix

Create .env.example with every key from .env and placeholder values.

## Ignoring this rule

Skip it everywhere in `devshield.yml`:

```yaml
ignore:
  - SH301
```

Or skip one line with a comment on that line or the line above:

```text
devshield-ignore: SH301
```
