# DX006: CI installs dependencies without caching

**Severity:** low · **Category:** developer_experience · **Applies to:** github_actions

## Why it matters

Reinstalling every dependency on each run slows feedback and burns CI minutes.

## How to fix

Use `cache:` on setup-node/setup-python/setup-php or add actions/cache.
