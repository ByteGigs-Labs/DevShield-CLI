# DX003: Workflow token permissions too broad

**Severity:** medium · **Category:** developer_experience · **Applies to:** github_actions

## Why it matters

Without an explicit permissions block the GITHUB_TOKEN may have write access to the repository, which a compromised step can abuse.

## How to fix

Add `permissions: contents: read` at the top and grant more per job only.
