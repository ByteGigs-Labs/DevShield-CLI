# DX002: No CI workflow

**Severity:** low · **Category:** developer_experience · **Applies to:** all projects

## Why it matters

Without CI, tests and security checks only run if someone remembers to run them.

## How to fix

Add a pipeline (for example GitHub Actions) that runs tests and `devshield scan`.

## Auto-fix

`devshield fix` can resolve this rule for the cases it can change safely. Preview it with
`devshield fix --dry-run --only DX002`.

## Ignoring this rule

Skip it everywhere in `devshield.yml`:

```yaml
ignore:
  - DX002
```

Or skip one line with a comment on that line or the line above:

```text
devshield-ignore: DX002
```
