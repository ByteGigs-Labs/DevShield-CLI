# SH014: Django accepts any Host header

**Severity:** medium · **Category:** security · **Applies to:** django

## Why it matters

ALLOWED_HOSTS = ['*'] turns off Django's Host header validation, which enables cache poisoning and password-reset poisoning attacks.

## How to fix

List the real host names in ALLOWED_HOSTS, for example ['example.com'].
