# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/ByteGigs-Labs/DevShield-CLI/security/advisories/new)
for this repository, and include steps to reproduce.

We aim to acknowledge reports within 3 business days.

## Supported versions

Only the latest released version receives security fixes.

## Scope

DevShield reads project files and never executes project code. Reports of the tool
running untrusted code, writing outside the scanned project, or leaking secrets it
finds are in scope.
